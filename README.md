# Подготовка к олимпиаде по физике · 10 класс

Статический сайт (тексты на украинском, как на самой олимпиаде): план підготовки, добірка задач прошлых лет и пробный вариант I этапа с решениями.

## Файлы

- `index.html` — план, темы, формат I этапа
- `zadachi.html` — подборка задач по темам со ссылками на официальные PDF
- `probnyi.html` — пробный вариант (5 задач, 3 часа, таймер, решения и критерии под спойлерами)
- `style.css` — оформление
- `.gitlab-ci.yml` — публикация на GitLab Pages
- `.nojekyll` — отключает Jekyll на GitHub Pages

Формулы рендерятся через MathJax с CDN, сборка не нужна.

## Публикация на GitHub Pages

1. Создайте репозиторий на github.com, например `olimp`.
2. Загрузите содержимое папки в корень репозитория (через «Add file → Upload files» или `git push`).
3. Settings → Pages → Build and deployment → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
4. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/` (для этого сайта — https://latik.github.io/olimp/).

## Публикация на GitLab Pages

1. Создайте проект на gitlab.com и загрузите в него все файлы, включая `.gitlab-ci.yml`.
2. Pipeline запустится сам; после его завершения адрес сайта будет в Deploy → Pages.

## Как печатать пробный вариант

Откройте `probnyi.html` и нажмите «Друкувати умови»: при печати решения скрываются, остаются только условия.
